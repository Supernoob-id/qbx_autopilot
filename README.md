# qbx_autopilot

A FiveM / GTA V client-side autopilot resource for waypoint driving, with an on-screen selector for choosing a driving mode.

**Created by:** Supernoob Indonesia

## Features

- Double-tap W to open the autopilot selector
- Use W / S to select a driving mode
- Press Enter to confirm or Backspace to cancel
- Drive to the active waypoint using the selected behavior
- Slow-down and arrival handling
- No item or server-side script required
- Uses ox_lib for notifications

## Controls

- Double-tap W: Open the selector
- W / S: Move through modes
- Enter: Confirm selection
- Backspace: Cancel the selector
- Tap W while autopilot is active: Stop autopilot

## Requirements

- FiveM server
- ox_lib

## Installation

1. Place the `qbx_autopilot` folder in your server's `resources` directory.
2. Make sure `ox_lib` is installed and started before this resource.
3. Add `ensure qbx_autopilot` to your `server.cfg`.
